# site-pra-todos-starter - FASE 08 OPERAÇÃO

Fonte da verdade: **GitHub**. Vercel preferencial via Git (auto-deploy main). Netlify adaptador via Git (mesmo repo).

## Setup
1. `git clone` este repo
2. `npm install`
3. Edite `/content/briefing.json` (1 página) e `/content/products.json` se Product
4. `npm run dev`
5. Push para GitHub -> Preview Vercel automático -> QA_CHECKLIST.md -> merge main

## Templates (5 arquétipos)
- local-business: Oficina, Barbearia, Comércio físico
- professional: Psicóloga, Advocacia (sem promessa resultado, OAB compliant)
- services: Encanador, Eletricista (orçamento via WhatsApp, foto do problema)
- product: Confeitaria, Loja Roupas/Sapatos (até 20 produtos simples)
- portfolio: futuro

## Produto Simples Congelado
foto + título + desc <=140 chars + CTA Peça pelo WhatsApp com nome do produto na mensagem
